Caracteristicas actuales

Todo lo que el proyecto genera y gestiona en la version 1.0.

⚙️

Motor de Generacion de Codigo

Engine basado en FreeMarker que produce un proyecto Spring Boot completo y compilable a partir de un solo request HTTP o formulario de UI.

FreeMarker ZIP 20+ artefactos
🏗️

Sistema de Atributos de Entidad

Definicion de campos personalizados por entidad con tipos Java, anotaciones Bean Validation y constraints JPA. Resolucion automatica de imports.

@NotBlank @NotNull @Email @Size
📋

Application Registry (CRUD API)

API REST completa para gestionar definiciones de aplicaciones antes de la generacion. Soporta jerarquia de dos niveles: aplicacion raiz → microservicios hijo.

REST CRUD Self-referential
🚀

Generator API

Endpoint de generacion con todas las opciones configurables: base de datos, version de Java, Spring Boot, Kafka, Swagger, arquitectura, empaquetado y mas.

H2 MySQL Kafka OpenAPI
🎛️

Process Manager

Permite iniciar, detener y consultar el estado de los proyectos generados directamente desde la UI de Scaffold, sin salir del navegador.

start stop status logs
🔌

Port Registry

Asignacion automatica de puertos desde 8101. Valida disponibilidad real via ServerSocket y persiste el estado en ports-used.properties.

Auto-assign ServerSocket
🐳

Docker Auto-Startup

Al arrancar Scaffold, detecta si Docker esta corriendo. Si no, lo lanza automaticamente (macOS o Linux) y espera hasta 60 segundos para que el daemon este disponible.

macOS Linux Docker Desktop
🖥️

Web UI (SPA)

Aplicacion de una sola pagina en vanilla HTML/CSS/JS sin dependencias externas. Incluye tres temas, editor de atributos dinamico y controles de proceso.

Dark Light Enterprise No framework
🌱

Data Seeder

En el primer arranque inserta automaticamente un registro raiz "Scaffold" en la base de datos como contenedor de todos los microservicios generados.

Auto-seed H2
